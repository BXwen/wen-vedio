## 全片读法

这不是“π 的历史课”，而是一条**用同一个圆连续变形**的视觉论证：3D 圆球 → 2D 圆 → 六边形 → 多边形阶梯 → 113355/355113 → 手机像素 → 低模 3D 球 → 自指结尾。每一段都在回答上一段留下的问题，画面只保留一个主对象。

## 时间轴

### 0–3s · 3D 球放大
画面：米白纸上一个光滑的白色 3D 球，柔光与投影；镜头推近，球面出现网格/低模直边；右上角“放大 ×9”。
文字：`游戏里很多圆滚滚的东西，放大看，全是直边。`
作用：先给一个可触摸的 3D 物体，再用放大动作把“圆=直边”变成亲眼所见，而不是一句定义。

### 3–15s · 周三径一与六边形
画面：2D 圆；红色直径与 1、2 标记；“周三径一”；三条直径拼不满一圈；把圆内接六边形点亮成红边。
文字：`古人算圆，常用「周三径一」；圆周算作直径的 3 倍。` → `可三条直径拼不满一圈——正好装满的，是里面的六边形。` → `刘徽点破：「周三」其实是圆里这个六边形的周长。` → `263 · 刘徽《九章算术注》`
作用：把“3”从一个错误答案改写成一个可验证的六边形事实。

### 15–27s · 6 → 12 → 24 → 48 → 96 → 192
画面：同一个圆连续翻倍；红边多边形；每一步给出“周长÷直径”的数值；18s 起出现一个大圆弧 + 小圆 + `放大 ×6/×12` 的窗口；20s 起左上出现竖排 `割之弥细，所失弥少`。
文字：`12 边形 周长÷直径≈3.1058`、`24 边形≈3.1326`、`48 边形≈3.1394`、`96 边形≈3.1410`、`192 边形≈3.1415`；`算到 192 边形，他取圆周率约 3.14`。
作用：把“逼近”做成一条可以读数的阶梯；放大窗让每一步的误差可见。

### 27–32s · 双界与 113355
画面：`3.1415926 < π < 3.1415927`；接着出现 `113355`，中间一条红线把数字劈开；`113 | 355`；`355/113`；小数展开；`小数点后六位，一位不差`。
文字：`祖冲之把它算得更细：3.1415926 到 3.1415927 之间。` → `他还给了个好记的分数：直径 113，周圆 355。` → `355÷113=3.1415929…`
作用：先给结果，再给一个可玩的数字机关；观众会记住 113355。

### 32–43s · 手机像素与 3D 游戏
画面：手机屏幕里一个圆；切到像素网格；一条红色水平线；`↑ 这一格 = 手机上 1 个像素`；`圆和 96 边形，最多差 0.29 个像素`。
文字：`用 96 边形画一个满屏的圆，在手机上差不到一个像素。` → `所以很多游戏和三维动画，至今还在用直边拼圆。`
作用：把古代近似值换算成观众每天看的屏幕，给出“这有什么用”的答案。

### 43–48s · 低模 3D 球
画面：一个低模二面/三角面 3D 球，慢慢旋转；`6 12 24 48 一刀一圈`；从多面体到球的连续感。
文字：`所以很多游戏和三维动画，至今还在用直边拼圆。`
作用：把“直边拼圆”从 2D 图扩展到 3D 物体，回扣开头的 3D 球。

### 48–55s · 自指结尾
画面：一个 192 条边的圆/六边形；`六条边` 品牌红印；`这条视频里的圆，也是我一刀刀切出来的。`；`周三径一里的 π`。
作用：用“这条视频里的圆也是直边拼的”把方法和作品本身扣在一起，形成一个闭环。

## 精华（可迁移的，不是照抄）

1. **物体先于概念**：先给一个 3D 圆球，再用放大动作把“直边”变成亲眼所见；不是先讲定义。
2. **让误差可触摸**：放大窗、手机像素、0.29 个像素，把“逼近”从抽象变成可比较的尺度。
3. **数字机关**：113355 → 113 | 355 → 355/113，六位不差；观众会记住这个数字。
4. **现代落点**：游戏和三维动画至今仍在用直边拼圆；低模球是这个论点的实物。
5. **自指结尾**：这条视频里的圆也是 192 条边，作品自己成为证据。
6. **节奏**：约 1–2 秒一个信息点，红边/红线/红印做强调，纸面+衬线字+小号英文保持统一。
