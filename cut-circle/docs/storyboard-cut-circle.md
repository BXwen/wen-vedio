# 《割圆术》分镜脚本

**副题**：用直线，量圆
**成片**：2:00 / 1920×1080 / 30fps / 3600 帧
**声音**：纯音乐，无旁白；文字即信息
**视觉**：宣纸、墨线、赭石、石青、朱砂；沿用《二十四节气》的纸张、竖排、朱印与 HUD 语法

---

## 一句话

一条曲线量不出来，就用越来越多的直线去逼近它；边数每翻一倍，误差约剩四分之一，直到直线与圆合体。

## 为什么这个题适合“无旁白”

- 只有一个变量：边数。
- 只有一个动作：翻倍。
- 只有一个结果：π。
- 数字本身就是叙事，不需要解释性旁白。
- 视觉可用一个圆加一组多边形完成，和现有“一个环生成 24 张卡”同构。

## 科学核（上屏前需核校）

| 事实 | 数值 / 出处 |
|---|---|
| 割圆术 | 刘徽《九章算术注》，263 年 |
| 六觚 | 正六边形周长 = 3 × 直径，π ≈ 3 |
| 192 觚 | 3.14（157/50） |
| 3072 觚 | 3.1416（3927/1250） |
| 祖冲之双界 | 3.1415926 < π < 3.1415927 |
| 密率 / 约率 | 355/113 / 22/7 |
| 祖冲之生卒 | 429–500 |
| 纪录 | 此后近九百年未被超越，直到十五世纪 |

注意：

- 割圆术是刘徽的方法，祖冲之是精算者；片头必须给刘徽署名，不能把发明归给祖冲之。
- “误差 ÷4”是边数较大时的渐近规律；六边形起步阶段偏差较大，分镜从 96 觚之后才把它当作精确比例。
- 祖冲之的计算方法没有传下来；“算法失传”可以作为第 9 卡的一行小字，但不要展开成阴谋论。

## 视觉系统

**色**

| 角色 | 色 | 用法 |
|---|---|---|
| 纸 | #F2EDE4 | 底 |
| 墨 | #1C1A17 | 圆、正文 |
| 赭石 | #B08A4A | 内接多边形 |
| 石青 | #3E5A72 | 外切多边形、注释 |
| 朱砂 | #B3271E | π、关键数字、印章 |

**形**

- 圆：一笔画成，起笔有墨点，收笔略过起点；静态笔刷滤镜烘成 PNG，避免逐帧湍流。
- 多边形：细线加顶点小圆点；顶点抖动按索引预计算，不逐帧随机。
- 空隙：多边形与圆之间的月牙，用极淡的赭石或石青洗出来；边数越多，洗得越薄。
- 数字：等宽数字，逐位落笔；关键数字用朱砂，其余用墨。

**字**

- 标题与大字：Noto Serif SC，500–700。
- 引文与注释：SimKai。
- 竖排只用于标题与引文；数据一律横排，保证可读。

**HUD 改造**

- 左上：割圆术 · 用直线量圆
- 右上：当前边数（六觚 / 十二觚 / … / 三千零七十二觚）
- 底部：十级翻倍梯 6 · 12 · 24 · 48 · 96 · 192 · 384 · 768 · 1536 · 3072，当前节点朱砂
- 右下：出处行，随章节切换
- 左下：秒数

## 逐卡详述

### 1 · 0:00–0:08 · 圆

- 画面：纸面；中心一滴墨（InkBloom，半径约 90px，8 帧铺开）。墨点边缘生出一根细线，绕中心一周，60 帧画完；收笔略过起点 8°，留下一个不闭合的小口。圆内一条直径从左到右画出，两端点朱砂小点。
- 大字：右侧竖排“割圆术”，逐字 6 帧擦入；下方小字“用直线，量圆”。
- 数据：无；只留一个极小的章节标记“数术 · 一”。
- 转场：圆与直径淡到 12% 墨色，作为后续卡片的底图。

### 2 · 0:08–0:18 · 以直量曲

- 画面：一条直尺（赭石细线，带刻度）从上方落到圆周上，切于一点。直尺两端与圆弧之间各留一个月牙空隙，空隙用淡墨洗亮，标“隙”。直尺换三个角度，隙仍在；第三次时，尺子停住，第一条六边形的边从尺子位置长出来。
- 大字：左侧横排“以直量曲”；下方小字“量不尽”。
- 数据：右上角小字“周三径一”出现，随即被一条细线划掉——古人的粗略说法不够。
- 转场：直尺绕切点旋转 60°，成为六边形的第一条边；其余五条边依次长出。

### 3 · 0:18–0:30 · 六觚

- 画面：六个顶点落在圆上，六条边连成；每条边的中点向圆弧鼓出一个月牙。六条边整体加粗一瞬，然后恢复细线。一个括号标出“6 × 半径 = 3 × 直径”。
- 大字：左下“六觚”；右下大数“3”。
- 数据：小字“正六边形 · 周长 = 3 × 直径”；“刘徽 · 263 年”在右上角出现。
- 转场：六个顶点各裂成两个，边数变 12。

### 4 · 0:30–0:42 · 倍之

- 画面：连续形变：12 → 24 → 48。每次翻倍，顶点从边中点“长”出来，月牙变薄。形变不切镜头，观众看到的是同一个东西越来越像圆。边数用三个数字在右上角滚动，当前数字朱砂。
- 大字：左侧“倍之”；小字“边数翻一倍”。
- 数据：底部梯 6 · 12 · 24 · 48 依次点亮。
- 转场：继续翻倍，进入 96。

### 5 · 0:42–0:54 · 一百九十二觚

- 画面：96 → 192。全屏看，多边形已接近圆；画面右下开一个圆形放大镜（直径 420px），放大一条边与弧的间隙，标出“矢高”。放大镜里的月牙随翻倍变薄。数字 3.14 从放大镜中心浮出。

## 制作清单

**直接复用**

- PaperBackground、InkBloom、VerticalText、Seal、Hud（改数据）、theme、fonts、timeline 模式。
- 现有配乐管线；把 beat grid 改为 60 BPM、120 拍即可。

**需要新建**

- `CirclePolygon`：给定边数、内接或外切、颜色，画出多边形与顶点；顶点抖动预计算。
- `SagittaInset`：放大镜，显示一条边与弧的间隙。
- `ErrorBand`：内外多边形之间的环带加对数误差尺。
- `NumberBracket`：上下双界加中央括号。
- `Fraction`：355/113 竖式。
- `DoublingLadder`：HUD 底部十级梯。

**性能**

- 圆与纸纹：静态滤镜或纹理烘成 PNG。
- 多边形：边数大于 768 时降低线宽和透明度，避免摩尔纹；3072 条线用单个 `<path>` 拼字符串，不要 3072 个 React 节点。
- 数字逐位动画：用 CSS transform 和 opacity，不用逐帧 filter。

**资产**

- 不需要画作。若想加一层“古籍感”，可在第 2 卡叠一张《九章算术》公有领域书页，透明度不超过 8%，2 秒即退。
- 字体沿用 Noto Serif SC 与 SimKai，避免新增网络字体。

## 事实核校

- 刘徽 263 年注《九章算术》，创割圆术；不要把发明归给祖冲之。
- 192 觚得 3.14；3072 觚得 3.1416；两个分数分别是 157/50、3927/1250。
- 祖冲之给出 3.1415926 < π < 3.1415927，密率 355/113，约率 22/7；生卒 429–500。
- 祖冲之的算法失传；其七位小数纪录保持近九百年，十五世纪被超越。
- “误差 ÷4”是 n 较大时的渐近规律，片中从 96 觚之后才作为比例使用。
